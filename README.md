# CPCC Bites - Campus Food & Café 

Welcome to the **CPCC Bites** website project repository! CPCC Bites is a fictional restaurant website concept tailored for college students, faculty, and campus staff. It provides an intuitive platform to explore daily menus, find campus pickup locations, and place sample orders seamlessly without needing to create an account.

---

## Project Overview

- **Project Name:** CPCC Bites - Campus Food & Café
- **Target Audience:** College Students, Faculty, and Staff
- **Goal:** Provide an easy-to-use, responsive campus food ordering portal.
- **Access Level:** Public (No account required for order simulations).

---

## Site Architecture & HTML Pages

The project consists of seven distinct HTML pages with a fully integrated global navigation bar:

1. **`index.html`** - Home page with a welcoming header, featured daily specials, active promotions, and navigation links.
2. **`menu.html`** - Full visual food menu presented in a structured CSS grid layout categorized by food type, descriptions, and pricing.
3. **`order.html`** - Interactive sample ordering system featuring real-time price calculations and customizable food options.
4. **`about.html`** - Background, mission statement, and culinary philosophy of CPCC Bites.
5. **`locations.html`** - Campus map guidance, physical building locations, and operational hours.
6. **`contact.html`** - Interactive contact form for customer inquiries and feedback.
7. **`faq.html`** - Frequently asked questions regarding pickup times, dietary options, and ordering policies.

##  Features & Technical Highlights

### Responsive & Layout Features
- **Fluid Layout:** Designed to work smoothly across Desktop, Tablet, and Mobile viewport sizes.

### Interactive Order Form (`order.html`)
- Customer details input (Name, Email, Phone).
- Pickup Date and Time pickers.
- Radio buttons for item sizing and portion choices.
- Quantity selectors and check boxes for optional add-ons/toppings.
- Range slider (e.g., spice level or portion preference).
- Category select dropdowns and special instructions text area.
- Client-side form validation using JavaScript.

###  JavaScript Functionality
- Real-time Date and Time display in header/footer.
- Estimated pickup time calculation upon ordering.
- Dynamic price total calculations updated live.
- Random order tracking number generator upon order submission.
- Custom notification alerts and UI feedback.
